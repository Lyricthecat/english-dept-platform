# 初中英语科组工作平台

初中英语教师专用工作平台，**纯前端 SPA，双击即用，完全离线可用**。

## 快速开始

### 方式一：单文件版（推荐，最简单）
1. 双击 `初中英语科组工作平台.html`（建议用 Chrome / Edge 打开）
2. 直接使用，无需安装、无需联网

### 方式二：文件夹版
1. 解压文件夹版压缩包
2. 双击 `index.html` 打开

> 使用说明与数据安全须知详见 [UserGuide.md](UserGuide.md)

## 技术栈

- HTML + CSS + JavaScript（三件套），无任何后端
- **localStorage 数据库**：所有数据自动存取，刷新 / 关闭不丢失
- **Chart.js 本地打包**（`lib/chart.umd.js`）：成绩走势图、比对图表，完全离线
- **SheetJS 本地打包**（`lib/xlsx.full.min.js`）：Excel 导入 / 导出，完全离线
- **File System Access API**：可绑定本地文件夹直接读写资料（需 Chrome / Edge）

## 功能模块

| 模块 | 功能 |
|------|------|
| 📋 工作计划 | 制定每周工作计划（**周历视图**展示一周每日工作安排）、确定每周授课进度、**一键生成表格（可自由选择时间跨度，多周自动分页/分工作表）**、复制到下周 |
| 👥 学生管理 | **一键添加班级和学生（全年级统一模板导入，按班级列自动分发 15 个班）**、班级档案卡片、名单增删改、单班 Excel 名单导入导出、一键搜索学生、学生卡片（历次成绩 + 走势图） |
| 📊 成绩管理 | 新建考试（1-15 班一键全选）、统一模板分班导入成绩、整表导入、一键比对分析（平均/最高/最低/分差/中位数/及格率/优秀率/低分率/得分率）、**试卷质量分析（难度系数/区分度）**、**7 类可视化图表（含箱线图/雷达图/直方图）**、**PDF 分析报告导出**、Excel 分析报告导出 |
| 📁 资料管理 | 课件 / 教案 / 试卷 / 练习题 / 默写卷 / 背诵资料 / 成绩 七类资料，可绑定本地文件夹直接读写 |
| ⚙️ 设置 | 基本信息、数据 JSON 备份导出 / 导入（覆盖 / 合并）、备份到文件夹 / 从文件夹恢复、清空数据 |

## 成绩导入模板说明

表头固定为：

```
班级 | 学号 | 姓名 | 语法选择 | 完形填空 | 阅读理解 | 回答问题 | 选词填空 | 完成句子 | 短文填空 | 作文 | 口语 | 总分 | 排名
```

- 「总分」「排名」留空时系统自动计算（总分 = 各题型之和，排名按总分班内自动排序，并列同名次）
- 各题型满分可在新建考试时按试卷实际调整（默认合计 120 分：语法选择 10 / 完形填空 10 / 阅读理解 30 / 回答问题 10 / 选词填空 5 / 完成句子 5 / 短文填空 5 / 作文 15 / 口语 30）
